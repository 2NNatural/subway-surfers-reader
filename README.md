# Subway Reader

A web app for reading long-form text with a chroma-keyed Subway Surfers character playing in the center. Text wraps around the character's real silhouette. Train obstacles scroll through the text while the character autonomously dodges between lanes.

**Status:** Core working — silhouette wrapping, trains with game-model sprites, autonomous character

## Quick Start

```bash
npm install
npm run dev
# → http://localhost:5173/
```
